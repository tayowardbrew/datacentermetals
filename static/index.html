Data Center Site Value Estimator

Search a location, draw a candidate parcel on satellite imagery, and estimate its implied power capacity, materials intensity (steel, copper, aluminum and battery-backup metals), shell construction cost, rack capacity and typical cooling method — with an auto-detected, confirmable land comparable, resolved to an implied site value in today's commodity terms.

Thesis: an early, defensible estimate of a data center site's implied collateral value can support an asset-backed debt argument before or during construction, applying a commodities / materials-intensity lens to AI infrastructure.

Methodology & provenance. Every benchmark figure (power density, steel & copper intensity, shell cost, rack density, cooling thresholds, land proxy) is documented in SOURCES.md with its source, URL and last-verified date. Live copper pricing is a genuine API call to Metals.Dev; where a live price or source is unavailable, that line is excluded and labelled rather than fabricated. Land value is a state / county-level comparable (quoted county DC-land deal, else the state's USDA raw-land floor), not a parcel-level appraisal. This is a portfolio MVP, not a formal valuation.
