Data Center Site Value Estimator

Estimate the implied power capacity, materials intensity (steel, copper), and total site value of a candidate data center parcel from raw coordinates and a building footprint.

Why it matters: an early, defensible estimate of a data center site's implied collateral value can support asset-backed debt raised against the site before or during construction. This connects a commodities/materials-intensity lens to AI infrastructure.

Portfolio MVP. Figures are researched benchmarks and regional proxies, not a formal appraisal. See README & SOURCES.md for full provenance.

Site inputs

Raw coordinates supported (no address required).

Manual input in v1. Automated size detection from imagery is a roadmap item.

Enter a location and footprint, then run the estimate.
